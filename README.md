# 🧠 Memory Card Game

## 📌 About the Project
Memory Card Game is an interactive and fun game designed to test and improve memory skills. Players flip cards to find matching pairs. The goal is to match all pairs with the fewest moves possible.

## 🚀 Features
- Interactive card-flipping functionality.
- Match pairs of identical cards.
- Tracks the number of moves.
- User-friendly and responsive design.
- Fun and engaging gameplay.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 🎮 How to Play
1. Start the game.
2. Click on any two cards to flip them.
3. If the cards match, they remain open.
4. If they don't match, they flip back.
5. Match all pairs to win the game.

## 💻 Installation
1. Clone this repository:
   ```bash
   git clone https://github.com/noorsaba02/Memory-Card-Game.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
